1. 系統概述與設計哲學

本專案在 soccer_game/ 資料夾內打造一款輕量、高流暢度、具備物理回饋與電競視覺美感的網頁版 2D 足球對戰遊戲。 整體專案全面參考 stock_dash 的工程架構規範：

極致效能與輕量

前端核心採用 HTML5 Canvas 2D 與純原生 JavaScript (ES6 Modules)，拒絕繁重 Node 構建與框架套件包袱，啟動即享穩定 60 FPS。

Django 後端與資料持久化

比照 stock_dash/mysite/ 架構，使用 Django 提供視圖、路由與 SQLite 儲存比賽戰績、勝率統計及排行榜 API。

Web Audio 原生合成

無需額外下載大型 MP3/WAV 音效檔案，直接透過瀏覽器振盪器合成逼真的踢球、中柱、哨音與進球歡呼。

獨立 Dark Mode 文檔體系

所有規格與開發邏輯一律維護為高可讀性的深色科技風 HTML 文件，隨時點開即可查閱。

2. 物理引擎與運算規範

遊戲的核心運動學包含真實的二維剛體碰撞、草皮滾動摩擦力衰減、彈性反彈與門柱圓角碰撞。

2.1 物理參數對照表

參數名稱 設定值 公式與運動學邏輯
足球摩擦力 (Friction) 0.985 每幀速度衰減：vx *= 0.985; vy *= 0.985;，平滑減速停球
邊界反彈係數 (Restitution) 0.82 邊界碰撞：vx = -vx * 0.82;
門柱反彈 (Post Bounce) 0.90 四個門柱圓柱碰撞箱彈射，帶出經典撞柱清脆角度與聲音
球員加速度 / 衝刺極速 3.8 ~ 5.5 px/f 方向鍵控制跑動，按住衝刺消耗體力 (Stamina Bar) 加速
蓄力射門速度 8.0 ~ 18.0 px/f 按住射門鍵蓄力 0~100%，依力量條向量噴射

⚽ 帶球磁吸與搶斷機制

當球員中心與足球距離小於 26px 時自動吸附於行進方向前方 18px 處。對手球員可施展滑鏟 (Tackle)，短暫使持球者失去球權並踢飛足球。

3. 電腦對手與門將 AI 決策邏輯

AI 採用分層狀態機 (FSM)，使單人模式具備挑戰性且表現自然：

  • 專職門將 (Goalkeeper)：在球門兩側立柱與足球連線形成的夾角平分線上保持動態站位；當足球逼近禁區且具射門威脅時，啟動側向飛撲與大腳解圍。
  • 對手球員 (Outfield Player)：
    • 逼搶攔截 (Chasing)：預判足球前進截點，加速攔截防守。
    • 進攻帶球 (Attacking)：奪球後主動朝對方球門推進，繞開玩家防守正面。
    • 瞄準射門 (Shooting)：距離球門適當角度時，自動瞄準遠角空檔蓄力射門。

4. 賽事機制、慢動作重播與音效

4.1 比賽流程

標準比賽時長為 90 秒真實時間（右上角倒數計時）。當足球穿過球門線時：

  1. 即刻觸發 15 幀畫面震動 (Screen Shake) 與 0.3x 慢動作進球重播。
  2. 螢幕彈出立體「GOAL!!」震撼橫幅與多彩紙屑粒子 (Confetti)。
  3. Web Audio API 播放進球哨聲與觀眾歡呼音效。
  4. 進球方比分 +1，倒數 1.5 秒後雙方重置回中圈開球。

5. 網站系統架構與 Django 後端 API

比照 stock_dash 的組織方式，路由與後端 API 均收斂於 mysite/： 

# mysite/game/urls.py
urlpatterns = [
    path('', views.game_home, name='game.home'),
    path('leaderboard/', views.leaderboard_page, name='game.leaderboard'),
    # AJAX 端點對齊 stock_dash 習慣
    path('ajax/save_match/', views.ajax_save_match, name='game.ajax.save_match'),
    path('ajax/leaderboard/', views.ajax_leaderboard, name='game.ajax.leaderboard'),
    path('ajax/stats/', views.ajax_stats, name='game.ajax.stats'),
]

戰績資料庫模型 (SQLite)

記錄每場比賽之雙方進球、勝負結果、難度、射門數、控球率以及玩家生涯最高連勝紀錄。

7. 分階段開發與驗收里程碑

階段 目標項目 驗收準則

Phase 2 Canvas 2D 球場渲染與足球物理剛體 流暢草皮標線、足球滾動衰減與門柱反彈正常
Phase 3 球員輸入控制、帶球機制與 AI 門將/防守 玩家能跑動帶球蓄力射門，AI 具備追球攔截與守門能力

Phase 5 慢動作重播、震動打擊感與彩花慶祝 進球瞬間 0.3x 慢動作定格，視覺反饋強烈
Phase 6 後端 SQLite 戰績持久化與排行榜 AJAX API 比賽結束自動回傳數據並於歷史儀表板正常查詢
