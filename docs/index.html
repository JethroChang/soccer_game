系統維護與架構原則 (Alignment with stock_dash)

  • 文檔一律強制為 HTML：所有技術文件均維持深色科技風格，確保在任何瀏覽器中雙擊即可高畫質閱讀。
  • 無臃腫第三方框架：前端採用純原生 HTML5/Canvas/CSS/JS，杜絕 Node build 耗時與版號衝突，啟動即玩。
  • 模組化代碼組織：物理引擎 (`physics.js`)、實體 (`player.js`, `ball.js`)、AI 決策 (`bot_ai.js`) 與音訊合成器 (`audio.js`) 相互解耦。
  • 嚴謹自動化驗收：後端變更執行 `python manage.py check`，並透過單元測試驗收戰績數據正確性。
